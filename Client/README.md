# Auren — Frontend Client

Auren is a premium iOS-inspired glassmorphism social chat and stories web application built with React, Vite, TypeScript, and Tailwind CSS.

## Features

- **Home Feed**: Real-time stories reel with animated glowing story rings, quick actions, recent messages feed, and quick shortcuts.
- **Chats & Messaging**: Direct messaging with conversation search, unread filtering, iOS-style glassmorphism chat threads, composer with attachments, emoji bar, and typing indicators.
- **Search & Discovery**: Discover users, instant search with clearable inputs, follow/requested/following state toggles, and recommended connections.
- **Activity & Notifications**: Categorized notifications (Today / This week), actionable follow requests with Accept / Decline workflows.
- **Anonymous Rooms**: Ephemeral peer rooms with custom auto-expiring codes, join/create flows, and zero-retention guarantees.
- **Story Creation Studio**: Camera capture simulation, interactive text-layer editor with draggable typography, curated gradient canvases, audience selection (Public vs Close Friends), and direct publishing.
- **Profile & Highlights**: Custom profile view, bio, stats, story highlights, active/archived stories switcher, and interactive Edit Profile modal.

## Design System

- **Glassmorphism**: Multi-layered backdrop blurs (`backdrop-filter: blur(28px) saturate(170%)`), translucent surface tints, delicate hairline specular borders, and deep drop shadows.
- **Color Palette**: Pitch black canvas (`#07070A`), deep obsidian surfaces (`#101014`, `#16161C`), soft electric blue (`#5A82FF`), and neon iris / violet accents (`#A88BFF`).
- **Typography & Radii**: Native iOS-inspired font stack with large radii (`16px` – `28px`) and tactile micro-interactions powered by Framer Motion.

## Getting Started

```bash
# Install dependencies
npm install

# Start the development server
npm run dev

# Build for production
npm run build
```
